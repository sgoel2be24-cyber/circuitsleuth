# Research protocol — fixed before held-out results

Date: 2026-10-26. Owner: Codex. All experiments are synthetic and local.

Preserve application source, API/artifact contracts, original data, locks, original benchmark and git state. Write only beneath this directory. Use PYTHONDONTWRITEBYTECODE=1 and redirect any store to this directory. Record source hashes before/after. Do not deploy, train large models, install dependencies or change git.

1. Validate implementation concerns with controlled probes: symmetric detection preprocessing, ECC direction, local ECC units, observation masks, matching and synthetic annotation coverage.
2. Generate disjoint procedural board identities: tuning 200001–200004, held-out test 300001–300008. No training occurs. Every capture/defect realization for one board remains in its board group. Original 30 cases are neither tuned nor regenerated.
3. Six capture profiles per board: clean, defects/mild, defects/gain-offset, defects/glare, defects/pose, defects/blur-noise. Three physical defects per board, rotating through the six generator types. The five defective captures share physical defects and are correlated. Two additional mismatched-board cases per split are refusal controls.
4. Compare legacy preprocessing; symmetric grayscale; symmetric + corrected ECC; and corrected-ECC detector ablations: small morphology, no median, bilateral, CLAHE detection, robust affine gain/offset, low-frequency multiplicative correction, eroded observation validity. Fixed choices, no parameter search. Lower candidate thresholds can improve recall at FP/budget cost: do not silently promote them.
5. Infer from pixels only. Ground truth and known synthetic pose enter evaluation only. Score maximum-cardinality one-to-one matching at IoU 0.15, 0.30, 0.50; retain legacy matching sensitivity and original scores separately. Keep registration refusals distinct from clean passes. Report candidate metrics separately from final claims. Report per-profile/type/size failures, false alarms per clean board and cluster uncertainty at board level. No candidate-level significance tests.
6. Select at most one optional detector enhancement from tuning only using micro F1 at 0.15, with no clean-FP increase and no candidate-recall decrease versus symmetric+ECC. Lock selection before test generation. Correctness variants remain diagnostic even if they regress. Run unchanged policy/verifier in memory on held-out candidates for legacy, symmetric+ECC and the selected variant (if different); preserve missing-view review.
7. Do not claim statistical superiority, production accuracy, cloud performance or expected percentage gains. Recommend promotion only through explicit regression, honest-review, tiny-defect, board-group and real-data gates.
